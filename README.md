# Python Estudos

Repositório utilizado para organizar meus estudos, exercícios, anotações e projetos desenvolvidos durante minha evolução em Python.

Aqui ficam separados conteúdos de lógica de programação, estruturas de dados, funções, modularização, tratamento de erros e pequenos projetos práticos feitos ao longo dos estudos.

A ideia é manter tudo organizado por conteúdo e projeto, funcionando tanto como histórico de evolução quanto como material de consulta futura.
