# Estudos DSA Python

Repositório utilizado para armazenar meus estudos, exercícios, anotações e projetos desenvolvidos durante o curso de Python da DSA (Data Science Academy).

Aqui ficam separados os conteúdos aprendidos ao longo do curso, juntamente com exercícios práticos e pequenos projetos feitos para reforçar lógica de programação, estrutura de dados, modularização e conceitos fundamentais da linguagem.

A ideia do repositório é servir tanto como histórico de evolução quanto como material de consulta futura.
