# Simulador de Batalha Pokémon

Projeto desenvolvido em Python com o objetivo de praticar lógica de programação, modularização, estruturas de repetição, condicionais, funções e organização de código.  
A ideia foi criar um sistema simples de batalhas entre Pokémons utilizando atributos como ataque, defesa, velocidade e vida (HP).

---

# Objetivos do Projeto

- Praticar lógica de combate
- Trabalhar com funções e módulos
- Utilizar dicionários para representar Pokémons
- Simular turnos de batalha
- Treinar organização de código em Python
- Melhorar a estrutura do projeto aos poucos conforme aprendo mais conteúdos
