# Conteúdos e Exercícios - Python

## Sobre esta pasta
Esta pasta reúne os conteúdos e exercícios desenvolvidos durante meus estudos em Python.  
Cada subpasta representa um tema específico da linguagem, contendo:
- exercícios práticos
- códigos comentados
- explicações sobre os conceitos utilizados
- exemplos de aplicação

O objetivo é documentar minha evolução na programação, praticando lógica, organização de código e recursos da linguagem Python através de exercícios progressivos.
