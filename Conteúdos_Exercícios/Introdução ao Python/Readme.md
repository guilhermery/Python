# Introdução ao Python

## Sobre o conteúdo
Nesta pasta foram desenvolvidos exercícios introdutórios da linguagem Python, abordando:
- entrada e saída de dados
- variáveis
- operações matemáticas
- manipulação de strings
- bibliotecas
- condicionais
- funções matemáticas
- listas

Foi o início do contato com lógica de programação utilizando Python, aprendendo conceitos básicos como variáveis, entrada de dados, operações matemáticas, condicionais e manipulação de strings. Essa etapa foi importante para entender como estruturar programas simples e desenvolver o raciocínio lógico na programação.
